# China Travel Recommendation System (KNN)

Dự án gợi ý địa điểm du lịch Trung Quốc dựa trên thuật toán K-Nearest Neighbors (KNN).

## Cấu trúc thư mục:
- `data/DATA.xlsx`: Cơ sở dữ liệu 100 địa điểm du lịch.
- `data/feedback.json`: Lưu trữ phản hồi người dùng.
